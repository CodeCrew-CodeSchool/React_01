# Intro to React

1stApp, challenge, and app01-03 were created using `npx create-next-app`

app04 was created using `npx create-react-app`

These tools effectively give you a codebase to start building a react app, but employ a slightly different product structure and build options.

Read more at [react.dev](https://react.dev) and [nextjs.org](https://nextjs.org)

## Comparing to plain HTML/JS/CSS

[Simple TodoList](https://github.com/CodeCrew-CodeSchool/HTML_vs_React/)

HTML explicitly spells out what will be displayed on a page. You can start to use JS to add some dynamic content.

To go down that rabbithole of dynamic content via JS, you arrive at a data driven UI library like React.

The components become less bound by the layout you create and your end result becomes dependent on the data/info/content that is being loaded into the layout.
